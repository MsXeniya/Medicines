# 💊 Medicines App — Полный гайд

Приложение для управления лекарствами с авторизацией и разделением данных по пользователям.

## ✨ Возможности

- ✅ Регистрация и вход
- ✅ Управление лекарствами (добавление, редактирование, удаление)
- ✅ Отметить лекарство как принятое
- ✅ Разделение лекарств между пользователями (видит только свои)
- ✅ Красивый современный интерфейс
- ✅ Токены сохраняются в localStorage
- ✅ Автоматическое обновление токена при истечении

## 🚀 Запуск

### Требования
- Node.js (v14+)
- npm или yarn

### Шаг 1: Установка зависимостей

```bash
# Корневая папка
npm install

# Сервер
cd server
npm install

# Клиент
cd ../client-react
npm install
```

### Шаг 2: Запуск сервера

```bash
cd server
node server.js
```

Сервер запустится на `http://localhost:5000`

### Шаг 3: Запуск клиента (в отдельной консоли)

```bash
cd client-react
npm start
```

Приложение откроется на `http://localhost:3000`

## 📱 Использование

### Регистрация
1. На странице входа нажмите "Нет аккаунта? Зарегистрироваться"
2. Введите имя пользователя и пароль
3. Нажмите "Зарегистрироваться"

### Вход
1. Введите существующее имя пользователя и пароль
2. Нажмите "Войти"

### Тестовые пользователи
- **xenia1** / `123456`
- **maya** / `123`

### Добавление лекарства
1. После входа в приложение вверху найдите форму "Добавить новое лекарство"
2. Введите название лекарства и время
3. Нажмите "Добавить"

### Управление лекарствами
- **✓ Принято** — отметить лекарство как принятое (кнопка изменит цвет)
- **↩️ Отменить** — убрать отметку о приёме
- **🗑️ Удалить** — удалить лекарство

### Профиль
Нажмите "Профиль" в навигации, чтобы посмотреть свои данные.

## 🔐 Безопасность

- Access Token действует 1 час
- Refresh Token действует 7 дней
- Токены сохраняются в localStorage (в production лучше использовать httpOnly cookies)
- Все запросы к `/api/medicines` требуют валидный access token
- Пользователь видит только свои лекарства (+ legacy-лекарства без userId)

## 🧪 Тестирование API через Postman

1. Импортируйте коллекцию: `postman/MedicinesLocal.postman_collection.json`
2. Импортируйте окружение: `postman/MedicinesLocal.postman_environment.json`
3. Выберите окружение MedicinesLocal
4. Выполняйте запросы по порядку (Login → Get Profile → Get Medicines → Create Medicine)

Подробнее: `postman/README.md`

## 🐛 Решение проблем

### Сервер не запускается
- Убедитесь, что порт 5000 свободен
- Проверьте, что Node.js установлен: `node --version`

### Клиент не подключается к серверу
- Убедитесь, что сервер запущен на порту 5000
- Проверьте в браузере консоль (F12 → Console) на ошибки

### Лекарства не сохраняются
- Убедитесь, что вы авторизованы (есть access token)
- Проверьте, что в заголовке Authorization передаётся correct token

### Видите лекарства других пользователей
- Это может быть, если это legacy-лекарства (без userId)
- Новые лекарства (с userId) видны только владельцу

## 📝 API Endpoints

### Авторизация
- `POST /api/auth/register` — регистрация
- `POST /api/auth/login` — вход
- `GET /api/auth/profile` — профиль (требует token)
- `POST /api/auth/refresh` — обновить access token
- `DELETE /api/auth/:id` — удалить пользователя (требует token)

### Лекарства
- `GET /api/medicines` — список лекарств (опционально: с token видны свои + legacy)
- `POST /api/medicines` — добавить лекарство (требует token)
- `PUT /api/medicines/:id/take` — отметить как принятое (требует token)
- `DELETE /api/medicines/:id` — удалить лекарство (требует token)
